# Catalog: modules

Every ship module, furniture piece and sealed container. 84 module defs are registered (`content.modules` = `modules.ts` + `furniture.ts` + `tiers.ts` + `landingPads.ts` + `groundMounts.ts`);
the build catalog test (`src/app/buildCatalog.test.ts`) requires every def to be reachable from a build tab, so any def here can be built by the player (except the landing pad and the ground turret mounts, which the prefab asteroid bases stand and the player never builds)
(Mk II/III and the flak cannon first need a blueprint). "Buildable only" means nothing places it on a ship, so it appears only if the player builds it.
Five sprite families have no def: cryo pod (not the prisoner holding: that is the stasis wheel), comms/medical/sensor consoles and workbench.
